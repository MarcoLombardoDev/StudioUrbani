# Fotografie dei profili delle recensioni

Cartella gestita dallo script: `scripts/fetch-reviews.mjs` scarica qui le
fotografie dei profili degli autori delle recensioni Google e cancella quelle
che Google non restituisce piu'. Non aggiungere file a mano.

Sono servite dal dominio dello Studio di proposito: linkarle da
`googleusercontent.com` sarebbe una richiesta a terze parti dal browser di chi
visita il sito.
